# uav-silm
UAV SILM project website (www.uavsilm.eu), served by GitHub Pages.

- `index.html`: the page
- `images/`: photos, renders and charts
- `fonts/`: self-hosted Bricolage Grotesque and IBM Plex Mono
- `assets/silm3d.js`: the 3D viewers (three.js, bundled; no external requests)
- `assets/silm.bin(.gz)`, `assets/silm.json`: airframe model, OpenFOAM surface pressure and streamlines
