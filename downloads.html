Download the software

Everything we use to plan a survey, set up the aircraft, fly it in the simulator and look at the pictures afterwards. Our own code is free to use, change and share under the MIT licence; the parts made by others keep their licences and are credited below.

Will it work on my aircraft? Yes, with
  • a fixed-wing plane running ArduPlane (ArduPilot)
  • a flight controller that can run Lua scripts (H7 or F7 boards such as the Matek H743)
  • an airspeed sensor, GPS with compass and a battery monitor
  • for recognition: a Raspberry Pi 4 and a network (RTSP) or USB camera; other cameras need a lens calibration
  • a laptop with Windows, macOS or Linux
It will not work with
  • quadcopters and other multirotors
  • DJI, PX4 or iNav flight controllers
  • small F4 boards that cannot run scripts
  • planes without an airspeed sensor

Even on the right aircraft: answer every question about your plane in the Ground Station, fly the mission in its simulator first, check the control directions on the bench, and get your flight authorisation.

The app · start here
UAV SILM Ground Station

Plan, send, launch and look at the pictures, with a guided setup for a new aircraft. Install it like any program; nothing else needed.

Windows installer macOS (Apple silicon) Linux

Windows may say the publisher is unknown, because the app is not code-signed: choose More info, then Run anyway. On macOS, open it the first time with right-click, Open. Checksums: SHA256SUMS.txt on the release page. The source and the model on their own are attached to each release.

You want toTake
Plan and fly a survey, see the picturesThe app above. Its guided setup takes a new aircraft step by step to ready-to-fly; GROUND_STATION.md explains every tab.
Change the software, or run it from sourceThe source: on GitHub, or the software zip attached to each release. Start Start Ground Station.bat (Windows) or start_ground_station.sh; FLIGHT_READY.md describes the whole procedure.
Set up the Raspberry Pi 4Nothing to download: the app installs it over your Wi-Fi (setup step 7) and updates it later.
Only the flight controller settingsThe app sends them itself. For Mission Planner, its Send tab saves the parameter file made for your aircraft (Full Parameter List, Load from file); the GPS-loss script is in the software zip (ardupilot/scripts).
Recognise tractors and livestockChoose "Ready-made" on the Ground Station's Camera tab: the model is inside the app. On its own it is attached to each release.

Read before flying: the software is tested in ArduPilot's simulator but not yet flown on a real aircraft. Fully automatic flight without a radio link needs the EASA "specific" category (an operational authorisation from Transpordiamet in Estonia), and taking pictures of people and property has its own rules. It comes as is, without any warranty.

The SHA-256 checksum of every file is in SHA256SUMS.txt on the release page. If the number you get is different, the file is damaged or not ours: do not use it, download it again.

ComputerCommand (in the folder with the file)
Windowscertutil -hashfile UAV-SILM-Ground-Station-Setup.exe SHA256
macOSshasum -a 256 UAV-SILM-Ground-Station-macos.zip
Linuxsha256sum -c SHA256SUMS.txt --ignore-missing

Everything is built on GitHub from a published commit of our repository (the release page names it); the zips are built the same way every time, so anyone can rebuild them and get the same checksums: python3 onboard/tools/build_downloads.py --release --out DIR.
