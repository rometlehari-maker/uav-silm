#  * tflite-runtime is the small inference-only package (no full TensorFlow).
#    Get the wheel matching your Python version from the Coral/TF project if pip
#    can't find it: https://github.com/google-coral/pycoral/releases
#  * picamera2 is only needed if camera.source == picamera (CSI camera).
#  * For a Coral USB accelerator also install libedgetpu1-std + pycoral.
