# Install on the Raspberry Pi 3 (Raspberry Pi OS).
#
#   sudo apt update
#   sudo apt install -y python3-opencv python3-numpy python3-yaml
#   python3 -m pip install -r requirements.txt
#
# Notes:
#  * On a Pi, prefer the apt python3-opencv/python3-numpy packages (prebuilt)
#    over pip wheels, which can be slow or fail to build. They satisfy the
#    opencv-python / numpy requirements below.
#  * The TFLite interpreter: the detector accepts any of three backends and
#    picks whichever is installed -- tflite-runtime (classic), ai-edge-litert
#    (its current renamed successor), or full tensorflow. On a modern Pi OS,
#    `pip install ai-edge-litert` is the reliable one; older setups use
#    tflite-runtime (wheels: https://github.com/google-coral/pycoral/releases).
#  * picamera2 is only needed if camera.source == picamera (CSI camera).
#  * For a Coral USB accelerator also install libedgetpu1-std + pycoral.
#  * TRAINING/EXPORT deps (NOT needed on the Pi -- install on your training box):
#      pip install ultralytics litert_torch
#    See training/README.md.
